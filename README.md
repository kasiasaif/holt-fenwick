# Holt + Fenwick

A sample website for a family-owned UK construction company. Inspired by the structure of large contractor sites — sectors, projects, yards, careers — with original copy and fictional contact details.

Live site: https://kasiasaif.github.io/holt-fenwick/

## Run locally

```bash
npm install
npm run dev
```

Then open the address Vite prints (port 4179).
